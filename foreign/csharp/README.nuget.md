# Apache Iggy C# SDK

Official C# client for [Apache Iggy](https://iggy.apache.org), a persistent message streaming platform.
Supports TCP and HTTP transports, targets .NET 8 and .NET 10.

## Installation

```bash
dotnet add package Apache.Iggy
```
